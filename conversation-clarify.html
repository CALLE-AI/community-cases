Conversation-Clarify
How it works Reuse the pattern Evidence & limits

Settle one
missing detail.

An email reply can sound like agreement while leaving a question open. Conversation-Clarify proposes one focused phone question, then prepares a draft for you to review.

Built by apple171 with CALL-E. Most Innovative · CALL-E Hackathon.

Watch the demo ↗ Explore the local demo ↓

A Chrome extension and Python server. The local fixture mode places no calls. Drafts still need your review and manual sending.

Find the unanswered part.

The extension reads the open Gmail conversation, identifies an unsettled choice or date and shows the question before any call.

  1. 1

    Inspect the finding

    Review the email evidence, proposed question, caller script and masked number. The number comes from the thread or from you.

  2. 2

    Approve one call

    Confirm the destination and question. The server sends the CALL-E request and polls for its result; the API credential stays on the server.

  3. 3

    Review the draft

    The app checks the answer and supporting words before drafting. You decide whether the result settles the question and how to reply.

A written example

This fictional exchange illustrates the flow. It is not a transcript or a new call result.

Question
Would you prefer the morning or afternoon visit?
Unclear reply
That sounds fine. The time is still missing.
Phone question
Ask which of the two times the person wants.
Review
Check the answer and quote before writing the reply.

A question with boundaries.

Use a phone call when a written exchange leaves one concrete detail unsettled. Keep the question, approval and evidence attached to that detail.

Open the author’s fixture walkthrough ↗

Try both outcomes.

The author provides a standalone browser harness and five saved outcomes: resolved, voicemail, no answer, unresolved and an answer outside the offered options. You can inspect the flow without a Gmail account or a real call.

  • Preview before dialing. Show the exact question and destination together.
  • Keep unresolved results visible. A completed call can still leave the original question unanswered.
  • Review the words. Compare the answer with the transcript and the allowed options, including negation.
  • Let the person send. A draft is an intermediate result, ready for review.

The application and companion skill are available at the reviewed revision. The app carries an MIT license.

Check the answer yourself.

  • The gate can accept an unsettled answer. At this revision, local probes using a negated option or two possible days still produced a draft. Inspect the answer and quote before using it.
  • Original-thread reply is manual. The implementation offers an in-panel draft, copy and a new Gmail compose window. It does not bind that compose window to the original thread or recipient.
  • Detection is limited. Rules cover selected patterns; Gmail markup can change. Live calling and a broad mailbox evaluation were not repeated for this guide.
