Get the workflow View the n8n node

What it does

Creates two call tasks, waits for each final status, and returns a compact result view with masked phone-bearing values.

What you need

An n8n deployment, a CALL-E API key, and phone numbers you own or have permission to call.

What you can change

Replace the sample IVR task, locale, metadata, and blocked placeholder numbers with your authorized test setup.

Maintenance

Maintained by CALL-E. Use the linked repositories for setup instructions, source code, and issue reporting.

Before running

This workflow can place real outbound calls. Keep it inactive until the API key, destination numbers, and task wording have been reviewed.
